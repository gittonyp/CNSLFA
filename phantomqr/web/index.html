Architecture — the direction flip

STUDENT (holds per-device key)
  ↓  dynamic signed QR every 15s  {sid,did,ctr,ts,nonce,mac}
PROFESSOR SCANNER (dumb camera, staff login only)
  ↓  POST /api/attendance/scan {token, session_id, staff_session}
SERVER (verifies HMAC, session, ts, counter, nonce, uniqueness)
  ↓
ATTENDANCE (ACCEPTED / blocked with reason)

Student never submits attendance. Professor device is the only writer. Server never trusts client time.

✓ HMAC-SHA256

Per-device 32-byte key. Constant-time compare. Tamper-evident.

✓ Dynamic QR

15s rotation, 60s server validity. Screenshot dies fast.

✓ Replay protection

Monotonic counter + once-only nonce + UNIQUE(sid,session).

✓ Tamper detection

sid/did/ctr/ts/nonce covered by MAC. Edit anything → INVALID_MAC.

✓ Staff-only submission

Anonymous POST rejected. Remote student at home has nothing to call.

✓ Offline queue

Scanner queues scans in localStorage, auto-uploads on reconnect.
